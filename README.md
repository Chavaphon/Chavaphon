# Hi, I'm Chavaphon 👋

CS student at KMUTT building stateful AI agents with Python and LangGraph.

I like building LLM systems that run locally, return structured output, and are grounded in real data through retrieval and web search.

## Featured projects

**[Local-LLM Discord Assistant](https://github.com/Chavaphon/Discord_Bot)**
Discord bot with LangGraph routing between direct answers and Tavily web search, RAG over uploaded PDFs (Chroma + `nomic-embed-text`), and channel summarization. Runs fully on local models via Ollama.

**[BreakDown](https://github.com/Chavaphon/BreakDown)**
FastAPI service that turns a goal into a schema-validated, step-by-step plan using a local LLM, LangGraph, and Pydantic structured output.

**[Google ADK Agent Series](https://github.com/Chavaphon/AI_Agent_Google_ADK)**
Progressive tutorial series covering custom tools, code execution, sequential and parallel multi-agent orchestration, persistent state with SQLite, and pytest testing.

## Tech stack

**Languages:** Python

**Backend & tools:** FastAPI, Pydantic, pytest, Git, Claude
